# dbt 使用边界

## 定位

dbt 只负责数据仓库数据库内的数据建模，不负责来源系统流程。

```text
dbt 的起点 = 数据仓库 ods/stg 层
dbt 的终点 = dwd / dim / dws / ads 等模型
```

## 不负责

dbt 不负责：

```text
飞书 API 读取
飞书多维表格回写
飞书节点分发
影刀或 Python 抓取
来源库业务校验
来源库流程状态流转
跨库抽取任务
```

这些属于来源业务系统或数据工程任务。

## 负责

dbt 负责：

```text
清洗入仓后的标准数据
建立统一字段口径
建设事实表和维度表
建设主题汇总表
建设报表和分析数据集市
维护模型依赖和测试
```

## 与 ELT 的关系

推荐链路：

```text
来源业务库
  -> Python/数据工程任务按 updated_at 增量入仓
  -> 数据仓库 ods/stg
  -> dbt transform
  -> dwd/dim/dws/ads
```

原则：

```text
来源库先把数据处理到可信。
数据工程任务负责把可信数据装载进数据仓库。
dbt 负责在数据仓库内做统一建模。
```
